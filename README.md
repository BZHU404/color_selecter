# 色研所 · CHROMA LAB

一个本地运行、无依赖的色彩解剖台，采用 Risograph 印刷实验室风格的视觉语言。选一枚颜色，查看它的全部数值、构成与色彩关系，并获得水彩、丙烯/油画、印刷油墨和纺织染料的现实复刻起点。

## 打开

直接双击 `index.html` 即可使用，也可以在目录中启动一个本地静态服务器：

```bash
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## 能做什么

- **取色**：在饱和度/明度色板上拖动，用色相滑杆、HEX 输入、系统取色器或浏览器 EyeDropper 屏幕吸管取色；也可以导入图片，点击取色或提取六色色谱。
- **色之档案**：HEX、RGB、HSL、HSV、HWB、CMYK、CIELAB、LCH、OKLCH、XYZ、相对亮度、前后景对比度，以及最近的中国传统色名称与色彩气质描述。右侧的当前色卡会随颜色实时更新，点击即可复制 HEX。
- **色彩关系**：单色、类似、互补、分裂互补、三角、四角配色；可点击任一色块继续探索；附带 WCAG 对比度与文字用色建议。
- **现实复刻**：
  - 水彩 / 丙烯 / 油画：推荐 2–3 种颜料、体积比例、模型预测色与 ΔE00、操作步骤和微调提示。
  - 印刷油墨：简化 CMYK 分色、TAC 提示，以及扩展色专色调墨配方。
  - 纺织染料：棉麻活性染料、羊毛真丝酸性染料、涤纶分散染料，按纤维切换染料用量（% o.w.f.）、助剂、温度/时间/浴比/pH 和工艺步骤。
- **带走**：下载 1400×1800 PNG 色卡、JSON 完整档案，或复制 CSS token / 完整文字档案 / 分享链接。
- **历史与分享**：颜色自动写入 URL hash（如 `#2F5D8C`），最近颜色保存在本地；不收集、不上传任何数据。
- **纸张底色**：顶部右可切换冷灰纸、暖白纸、雾蓝纸三种底色，选择会保存，并同步用于导出的 PNG 色卡。
- **快捷键**：`R` 随机颜色，`E` 屏幕吸管（浏览器支持时），`I` 图片取色；在色板上可用方向键微调，按住 `Shift` 加速。

## 关于准确性

这是一个设计、沟通与打样辅助工具，不是分光测色仪：

- CMYK 为不做 ICC 转换的简易换算，不能直接作为印厂最终分色数据。
- 颜料配方由三通道单常数 Kubelka–Munk 近似模型生成，结合了颜料的着色力与常见调色习惯，但品牌、批次、底材、厚度与光源都会改变最终结果。
- 纺织染料配方由目标色的明度与色相分解推导方向，纤维种类、前处理、水质、pH、温度、助剂和染料批次都会显著影响上染。
- 任何用于作品、产品或量产的配方，都应先在真实材料上打小样，并在目标光源下比对。

染料、酸碱与溶剂请佩戴手套和护目镜，在通风环境操作，并按当地规范处理废液。高温高压染色需要专业设备。

## 文件

- `index.html` — 页面结构
- `styles.css` — 基础视觉系统与响应式布局
- `theme.css` — Risograph 实验室主题覆盖层
- `color-engine.js` — 色彩数学、调色模型、命名与染料公式（无依赖）
- `app.js` — 交互、图片取色与导出
